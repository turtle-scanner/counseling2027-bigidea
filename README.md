# 🎯 2027 전문상담 임용고시 핵심교재 웹앱 (ADHD 맞춤형 PWA)

구글 드라이브의 김진구 개념코드 및 2026 기출 전수 분석을 기반으로 제작된 **스마트폰/태블릿/PC 겸용 인터랙티브 교재 웹앱**입니다.
Progressive Web App(PWA) 기술이 내장되어 있어 **깃허브에 올린 후 스마트폰 홈 화면에 '앱으로 설치'하면 병원이나 이동 중 와이파이가 없어도 100% 오프라인 학습**이 가능합니다.

---

## 🏥 병원/외부에서 스마트폰 앱으로 사용하는 방법 (GitHub Pages 무료 배포)

### 1단계: 깃허브(GitHub) 새 저장소(Repository) 만들기
1. [GitHub](https://github.com)에 로그인 후 우측 상단의 **[+] -> [New repository]** 클릭
2. Repository name에 counseling2027 (또는 원하는 이름) 입력
3. **Public** 선택 후 하단의 **[Create repository]** 클릭

### 2단계: 내 컴퓨터에서 깃허브로 업로드
이 폴더에서 깃허브_업로드_원클릭.bat를 실행하거나 터미널에서 아래 명령어 실행:
`ash
git remote add origin https://github.com/당신의깃허브아이디/counseling2027.git
git branch -M main
git push -u origin main
`

### 3단계: GitHub Pages 무료 웹사이트 활성화 (3초 완성)
1. 깃허브 저장소 페이지의 상단 메뉴에서 **[Settings]** 클릭
2. 좌측 메뉴에서 **[Pages]** 클릭
3. **Branch** 설정을 None에서 **main**으로 바꾸고 **[Save]** 클릭!
4. 약 1분 후 상단에 나만의 교재 주소가 생성됩니다:
   👉 https://당신의깃허브아이디.github.io/counseling2027/

## 📱 스마트폰/태블릿 '진짜 앱'으로 설치하기

### 🍏 아이폰 / 아이패드 (iOS)
1. Safari 브라우저에서 위 깃허브 페이지 주소로 접속
2. 하단 중앙의 **[공유 버튼 (네모에 화살표 ↑)]** 터치
3. **[홈 화면에 추가]** 터치
4. 이제 홈 화면에 **'전문상담 임용' 앱 아이콘**이 생기며, 누르면 주소창 없이 전체 화면 앱으로 실행됩니다!

### 🤖 갤럭시 / 안드로이드 (Android)
1. Chrome 또는 삼성 인터넷에서 위 주소로 접속
2. 우측 상단 **[점 3개 (메뉴)]** 또는 하단 배너 터치
3. **[홈 화면에 추가]** 또는 **[앱 설치]** 터치
4. 홈 화면에 설치되어 와이파이가 끊겨도 완벽히 오프라인으로 작동합니다.

## 💻 PC에서 앱 모드로 바로 열기
- 폴더 내 교재_앱으로_열기.bat를 더블 클릭하시면 브라우저 상단 주소창과 탭이 없는 **깔끔한 전용 데스크톱 앱 창**으로 즉시 열립니다.

# 🎯 counseling2027 bigidea - 전문상담 임용고시 핵심교재 웹앱 (PWA)

김진구 강사 최신 개념코드 및 2026학년도 기출 전수 분석을 기반으로 제작된 **스마트폰/태블릿/PC 겸용 인터랙티브 핵심 교재 웹앱**입니다.
Progressive Web App(PWA) 기술이 내장되어 있어 **스마트폰 홈 화면에 앱으로 설치하면 병원이나 이동 중 와이파이가 없어도 100% 오프라인 학습**이 가능합니다.

---

## 🌐 실시간 웹앱 주소 (GitHub Pages)
👉 **https://turtle-scanner.github.io/counseling2027-bigidea/**

---

## 🏥 병원/외부에서 스마트폰 앱으로 설치하는 방법

### 🍏 아이폰 / 아이패드 (iOS Safari)
1. Safari 브라우저에서 위 주소(https://turtle-scanner.github.io/counseling2027-bigidea/)로 접속
2. 하단 중앙의 **[공유 버튼 (네모에 화살표 ↑)]** 터치
3. **[홈 화면에 추가]** 터치
4. 홈 화면에 **'counseling2027 bigidea' 앱 아이콘**이 생기며, 누르면 주소창 없이 전체 화면 앱으로 실행됩니다!

### 🤖 갤럭시 / 안드로이드 (Android Chrome/삼성인터넷)
1. 크롬 또는 삼성 인터넷에서 위 주소로 접속
2. 우측 상단 **[점 3개 (메뉴)]** 또는 하단 배너 터치
3. **[홈 화면에 추가]** 또는 **[앱 설치]** 터치
4. 홈 화면에 설치되어 와이파이가 끊겨도 완벽히 오프라인으로 작동합니다.

---

## 💻 PC에서 앱 모드로 바로 열기
- 폴더 내 교재_앱으로_열기.bat를 더블 클릭하시면 브라우저 상단 주소창과 탭이 없는 **깔끔한 전용 데스크톱 앱 창**으로 즉시 열립니다.
